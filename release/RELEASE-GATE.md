# Separate Public Release Gate

A private render does not become public automatically.

## Required evidence

- [ ] Composition and lyric authorship documented
- [ ] Samples, loops, performances, and artwork rights cleared
- [ ] Contributor credits and splits confirmed
- [ ] Final WAV master rendered and read back
- [ ] MIDI and requested stems exported
- [ ] SHA-256 checksums recorded
- [ ] Technical QA complete
- [ ] Human listening review complete
- [ ] Mastering measurements recorded
- [ ] Metadata and artwork verified
- [ ] Release destination, date, and territory confirmed
- [ ] Human release approval recorded
- [ ] Public listing verified after publication

## Approval record

Create one approval record per release under evidence/approvals/ with release_id, exact asset filenames and hashes, rights/visibility review, destination, planned publication date, approving person and timestamp, decision, and restrictions.

Never commit secrets, private signing keys, or credentials. A successful render or passing automated test is not public-release authorization.
